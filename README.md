# MiniGames

A web application with a collection of mini-games, developed as part of the Rolling Scopes School Qualifying Stage.

## About the project

MiniGames is a browser-based application designed to provide a collection of interactive mini-games with a responsive and adaptive user interface.

The project is developed according to the Rolling Scopes School requirements and design specifications.

## Technologies

- TypeScript
- Vite
- Sass

## Getting Started

### Installation

Install the project dependencies:

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

The application will be available at the local address provided by Vite.

### Production Build

Create a production build:

```bash
npm run build
```
